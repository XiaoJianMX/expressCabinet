# 智能快递柜管理系统 (Express Cabinet System)

## 项目简介

本项目是一个基于 Qt C++ 开发的智能快递柜图形用户界面 (GUI) 应用程序。旨在模拟和管理快递柜的日常操作，包括用户存件、取件以及快递员的管理等功能。

## 主要功能

*   **存件 (Deposit):** 用户可以将包裹存入快递柜。 (相关代码位于 `cun` 目录)
*   **取件 (Pickup):** 用户可以通过凭证或验证码从快递柜取出包裹。(相关代码位于 `qu` 目录)
*   **寄件 (Send):** 用户可以通过快递柜寄送包裹。(相关代码位于 `ji` 目录)
*   **快递员操作 (Deliveryman Operations):** 快递员可以登录系统进行包裹投放、管理等操作。(相关代码位于 `deliveryman` 目录)
*   **主界面 (Main Interface):** 提供用户友好的图形界面，整合各个功能模块。(相关代码位于 `main` 目录)

## 技术栈

*   **语言:** C++
*   **框架:** Qt 5.12.9 
*   **构建系统:** CMake (`CMakeLists.txt` 文件)
*   **IDE:** Qt Creator  vscode
